# Индиго Технологии

Статический сайт компании по ремонту и обслуживанию пищевого оборудования в Москве.

## Публикация на GitHub Pages

1. Создайте **публичный** репозиторий на [GitHub](https://github.com/new), например `indigo-tehnologii`. При создании не добавляйте README и другие файлы — он уже есть в проекте.
2. Загрузите в корень репозитория содержимое этой папки, включая `.nojekyll`, фотографии `1.jpg`–`4.jpg`, файлы сайта и папку `assets`. Основная ветка должна называться `main`.
3. В настройках репозитория **Settings → Pages → Build and deployment → Source** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`.
4. Дождитесь публикации. Ссылка появится в **Settings → Pages**.

Обычный адрес сайта: `https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

Анкета на сайте формирует текст заявки для копирования. Для автоматической отправки нужен отдельный адрес получения заявок и обработчик формы.
